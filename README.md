Image Gallery

A responsive Pinterest-inspired Image Gallery built using HTML, CSS, and JavaScript, powered by the Pexels API.

Features
Search images using keywords
Search with Enter key support
Category-based image browsing
Dynamic image loading from Pexels API
Like / Unlike images
Save / Unsave images
View liked images section
View saved images section
Local Storage persistence
Loading spinner during API requests
Responsive gallery layout
Pinterest-style user interface

Technologies Used

HTML5
CSS3
JavaScript (ES6)
Pexels API
Local Storage
