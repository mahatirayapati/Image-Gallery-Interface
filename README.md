]# Image Gallery

A responsive Pinterest-inspired Image Gallery built using **HTML, CSS, and JavaScript**, powered by the **Pexels API**. The application allows users to search for high-quality images, like their favorites, save images for later viewing, and enjoy a clean Pinterest-style browsing experience.

## Features

* Search images using keywords
* Search with Enter key support
* Category-based image browsing
* Dynamic image loading from Pexels API
* Like / Unlike images
* Save / Unsave images
* View Liked Images section
* View Saved Images section
* Local Storage persistence
* Loading spinner during API requests
* Responsive gallery layout
* Pinterest-inspired user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Pexels API
* Local Storage

## How It Works

1. Enter a keyword in the search bar or select a category.
2. Images are fetched dynamically from the Pexels API.
3. Like images using the heart button.
4. Save images using the download button.
5. Access liked and saved images through their dedicated sections.
6. All liked and saved images remain available after page refresh using Local Storage.



Built as a frontend project to practice API integration, DOM manipulation, Local Storage, and responsive web design.
